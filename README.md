# Playground

<img src="https://raw.githubusercontent.com/shadrackb1/shadrackb1/main/mini-games.svg" width="100%" alt="mini games preview" />

Mini games and interaction experiments. No frameworks. No build step. Each file is the whole app.

## Games

| Game | Controls | File |
| --- | --- | --- |
| Snake | Arrows / WASD / swipe | [snake.html](./snake.html) |
| Pong | Mouse / touch | [pong.html](./pong.html) |
| Memory | Click | [memory.html](./memory.html) |
| Reaction | Click | [reaction.html](./reaction.html) |

## Run

Open any HTML file in a browser, or enable GitHub Pages on this repo.
